# Microsoft Agent Framework による Agent 開発 (C#)

Microsoft Agent Framework SDK (C#/.NET) を使って、Microsoft Foundry のモデルに接続し、シンプルなエージェント、関数ツール、複数ターン会話、マルチエージェントワークフローを実装する方法を学びます。

---

## 1. 開発環境のセットアップ

### 1-1. 前提条件の確認

本ハンズオンでは以下が必要です。

- **.NET 10.0 以上** がインストールされていること
- **Azure サブスクリプション** と **Microsoft Foundry リソース** が作成済みであること ([1. Azure ポータルから Microsoft Foundry リソースを作成](../1_basicagent.md#1-azure-ポータルから-microsoft-foundry-リソースを作成) 参照)
- **gpt-4.1** や などのモデルがデプロイ済みであること
- **Azure CLI** が使えること

### 1-2. 作業用フォルダーの作成

ターミナル (またはコマンドプロンプト) を開き、作業用のフォルダーを作成します。

```bash
mkdir agent-framework-hol
cd agent-framework-hol
```

### 1-3. Project Endpoint の確認

[Microsoft Foundry ポータル](https://ai.azure.com/nextgen) を開き、対象プロジェクトの **概要** 画面を表示します。

![](../images/3-1-01.png)

画面内に表示される **Project endpoint** を確認し、環境変数に設定します。

```bash
export FOUNDRY_PROJECT_ENDPOINT="https://<your-foundry-service>.services.ai.azure.com/api/projects/<your-project>"
export FOUNDRY_MODEL="gpt-4.1"
```

## 2. シンプルなエージェントの作成

### 2-1. Azure へのサインイン

アプリを実行する前に、Azure CLI でサインインしておきます。

```bash
az login
```

ブラウザが開き、Azure アカウントへのサインインを求められます。

![](../images/3-2-01.png)

### 2-2. Hello Agent の作成

`hello_agent.cs` という名前のファイルを作成して、以下のコードを記述します。

```csharp
#!/usr/bin/dotnet run
#:package Microsoft.Agents.AI.Foundry@1.1.0
#:package Azure.Identity@1.20.0

using Azure.AI.Projects;
using Azure.Identity;
using Microsoft.Agents.AI;

string endpoint = Environment.GetEnvironmentVariable("FOUNDRY_PROJECT_ENDPOINT")
    ?? throw new InvalidOperationException("FOUNDRY_PROJECT_ENDPOINT is not set.");
string deploymentName = Environment.GetEnvironmentVariable("FOUNDRY_MODEL")
    ?? "gpt-4.1";

AIAgent agent = new AIProjectClient(new Uri(endpoint), new DefaultAzureCredential())
    .AsAIAgent(
        model: deploymentName,
        instructions: "あなたは親切な AI アシスタントです。日本語で簡潔に回答してください。",
        name: "HelloAgent");

// 通常応答
Console.WriteLine(await agent.RunAsync("Microsoft Foundry とは何ですか？ひとことで教えてください。"));

// ストリーミング応答
Console.Write("Streaming: ");
await foreach (var update in agent.RunStreamingAsync("AI エージェントの活用例を 1 つだけ教えてください。"))
{
    if (!string.IsNullOrEmpty(update.Text))
    {
        Console.Write(update.Text);
    }
}
Console.WriteLine();
```

### 2-3. アプリの実行

以下のコマンドでファイルを直接実行します。

```bash
dotnet run hello_agent.cs
```

正常に実行されると、まず通常応答が表示され、その後ストリーミングで回答が順次表示されます。

![](../images/3-2-02.png)

## 3. ツールを使ったエージェントの作成

### 3-1. 関数ツールの追加

最新の .NET サンプルでは、関数をツールとして登録し、エージェントに利用させる構成が基本です。

`weather_agent.cs` という名前のファイルを作成して、以下のコードを記述します。

```csharp
#!/usr/bin/dotnet run
#:package Microsoft.Agents.AI.Foundry@1.1.0
#:package Microsoft.Extensions.AI@10.5.0
#:package Azure.Identity@1.20.0

using System.ComponentModel;
using Azure.AI.Projects;
using Azure.Identity;
using Microsoft.Agents.AI;
using Microsoft.Extensions.AI;

[Description("Get the weather for a given location.")]
static string GetWeather([Description("The location to get the weather for.")] string location)
    => $"{location} の天気は晴れ、最高気温 25°C です。";

string endpoint = Environment.GetEnvironmentVariable("FOUNDRY_PROJECT_ENDPOINT")
    ?? throw new InvalidOperationException("FOUNDRY_PROJECT_ENDPOINT is not set.");
string deploymentName = Environment.GetEnvironmentVariable("FOUNDRY_MODEL")
    ?? "gpt-4.1";

AITool weatherTool = AIFunctionFactory.Create(GetWeather);

AIAgent agent = new AIProjectClient(new Uri(endpoint), new DefaultAzureCredential())
    .AsAIAgent(
        model: deploymentName,
        instructions: "あなたは天気案内アシスタントです。天気を聞かれたら GetWeather ツールを使って答えてください。",
        name: "WeatherAssistant",
        tools: [weatherTool]);

AgentSession session = await agent.CreateSessionAsync();
Console.WriteLine(await agent.RunAsync("東京の天気を教えてください。", session));
```

```bash
dotnet run weather_agent.cs
```

![](../images/3-3-01.png)

> 本番環境では、ツールの承認フローやログ出力の追加も検討してください。

## 4. 複数ターンの会話への対応

Microsoft Agent Framework SDK では、同じセッションを使い回すことで会話の文脈を維持できます。

`multi_turn_agent.cs` という名前のファイルを作成して、以下のコードを記述します。

```csharp
#!/usr/bin/dotnet run
#:package Microsoft.Agents.AI.Foundry@1.1.0
#:package Azure.Identity@1.20.0

using Azure.AI.Projects;
using Azure.Identity;
using Microsoft.Agents.AI;

string endpoint = Environment.GetEnvironmentVariable("FOUNDRY_PROJECT_ENDPOINT")
    ?? throw new InvalidOperationException("FOUNDRY_PROJECT_ENDPOINT is not set.");
string deploymentName = Environment.GetEnvironmentVariable("FOUNDRY_MODEL")
    ?? "gpt-4.1";

AIAgent agent = new AIProjectClient(new Uri(endpoint), new DefaultAzureCredential())
    .AsAIAgent(
        model: deploymentName,
        instructions: "あなたは会話の文脈を理解する AI アシスタントです。日本語で簡潔に回答してください。",
        name: "ConversationAgent");

AgentSession session = await agent.CreateSessionAsync();

Console.WriteLine(await agent.RunAsync("私の名前は Ayako で、趣味は登山です。", session));
Console.WriteLine();
Console.WriteLine(await agent.RunAsync("私について覚えていることを教えてください。", session));
```

```bash
dotnet run multi_turn_agent.cs
```

## 5. マルチエージェントワークフローの作成

複数のエージェントを順番に連携させるワークフローも、最新の SDK では簡潔に記述できます。ここでは、下書きを作るエージェントとレビューするエージェントを順番につなぎます。

- **writer**: たたき台の文章を作成する
- **reviewer**: writer の出力を見て改善する

### 5-1. ワークフローの実装

`multi_agent_workflow.cs` という名前のファイルを作成して、以下のコードを記述します。

```csharp
#!/usr/bin/dotnet run
#:package Microsoft.Agents.AI.Foundry@1.1.0
#:package Microsoft.Agents.AI.Workflows@1.1.0
#:package Azure.Identity@1.20.0

using Azure.AI.Projects;
using Azure.Identity;
using Microsoft.Agents.AI;
using Microsoft.Agents.AI.Workflows;

string endpoint = Environment.GetEnvironmentVariable("FOUNDRY_PROJECT_ENDPOINT")
    ?? throw new InvalidOperationException("FOUNDRY_PROJECT_ENDPOINT is not set.");
string deploymentName = Environment.GetEnvironmentVariable("FOUNDRY_MODEL")
    ?? "gpt-4.1";

AIProjectClient projectClient = new(new Uri(endpoint), new DefaultAzureCredential());

AIAgent writer = projectClient.AsAIAgent(
    model: deploymentName,
    instructions: "ユーザーの依頼に対して、簡潔な説明文を日本語で作成してください。",
    name: "writer");

AIAgent reviewer = projectClient.AsAIAgent(
    model: deploymentName,
    instructions: "直前の回答をレビューし、より分かりやすい改善版を日本語で返してください。",
    name: "reviewer");

AIAgent workflowAgent = AgentWorkflowBuilder.BuildSequential(writer, reviewer).AsAIAgent();

string? lastAuthor = null;
await foreach (var update in workflowAgent.RunStreamingAsync("Microsoft Foundry の特徴を 3 つ挙げてください。"))
{
    if (string.IsNullOrEmpty(update.Text))
    {
        continue;
    }

    if (lastAuthor != update.AuthorName)
    {
        lastAuthor = update.AuthorName;
        Console.WriteLine();
        Console.WriteLine($"[{update.AuthorName}]");
    }

    Console.Write(update.Text);
}
Console.WriteLine();
```

### 5-2. ワークフローの実行

```bash
dotnet run multi_agent_workflow.cs
```

ワークフローが順に実行され、最終的に reviewer が整えた回答が表示されます。

![](../images/3-4-01.png)

> **動作の流れ**
> 1. writer が最初の回答案を作成します。
> 2. reviewer がその内容を引き継いで改善します。
> 3. 整理された最終回答が順に表示されます。

## まとめ

本ハンズオンでは、Microsoft Agent Framework SDK を使って以下を学びました。

| 内容 | 概要 |
|---|---|
| シンプルなエージェントの作成 | `AsAIAgent(...)` と `RunAsync(...)` を使った基本的な実装方法 |
| ツールの追加 | `AIFunctionFactory.Create(...)` で関数ツールを登録する方法 |
| 複数ターンの会話 | `AgentSession` を使って文脈を維持する方法 |
| マルチエージェントワークフロー | `AgentWorkflowBuilder.BuildSequential(...)` で複数エージェントを連携させる方法 |

最新の C# サンプルでは、Agent Framework を使って Foundry モデルと自然に接続し、単体エージェントからマルチエージェントワークフローまで一貫した書き方で実装できます。
