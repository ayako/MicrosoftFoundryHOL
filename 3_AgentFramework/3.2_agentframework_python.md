# Microsoft Agent Framework による Agent 開発 (Python)

Microsoft Agent Framework SDK (Python) を使って、Microsoft Foundry のモデルに接続し、シンプルなエージェント、関数ツール、複数ターン会話、マルチエージェントワークフローを実装する方法を学びます。

---

## 1. 開発環境のセットアップ

### 1-1. 前提条件の確認

本ハンズオンでは以下が必要です。

- **Python 3.10 以上** がインストールされていること
- **Azure サブスクリプション** と **Microsoft Foundry リソース** が作成済みであること ([1. Azure ポータルから Microsoft Foundry リソースを作成](../1_basicagent.md#1-azure-ポータルから-microsoft-foundry-リソースを作成) 参照)
- **gpt-4.1** などのモデルがデプロイ済みであること
- **Azure CLI** が使えること

### 1-2. プロジェクトの作成とパッケージのインストール

ターミナル (またはコマンドプロンプト) を開き、作業用フォルダーと仮想環境を作成して必要な Python パッケージをインストールします。

```bash
mkdir agent-framework-hol
cd agent-framework-hol
python -m venv .venv
source .venv/bin/activate
pip install -U agent-framework azure-identity python-dotenv
```

| パッケージ | 説明 |
|---|---|
| `agent-framework` | Microsoft Agent Framework SDK 本体 |
| `azure-identity` | Azure への認証 (`AzureCliCredential` など) を提供 |
| `python-dotenv` | `.env` ファイルから環境変数を読み込むための補助パッケージ |

### 1-3. Project Endpoint の確認

[Microsoft Foundry ポータル](https://ai.azure.com/nextgen) を開き、対象プロジェクトの **概要** 画面を表示します。

![](../images/3-1-01.png)

画面内に表示される **Project endpoint** を確認し、環境変数に設定します。

```bash
export FOUNDRY_PROJECT_ENDPOINT="https://<your-foundry-service>.services.ai.azure.com/api/projects/<your-project>"
export FOUNDRY_MODEL="gpt-4.1"
```

`.env` ファイルを使う場合は、以下のように保存しても構いません。

```env
FOUNDRY_PROJECT_ENDPOINT=https://<your-foundry-service>.services.ai.azure.com/api/projects/<your-project>
FOUNDRY_MODEL=gpt-4.1
```

## 2. シンプルなエージェントの作成

### 2-1. Azure へのサインイン

スクリプトを実行する前に、Azure CLI でサインインしておきます。

```bash
az login
```

ブラウザが開き、Azure アカウントへのサインインを求められます。

![](../images/3-2-01.png)

### 2-2. Hello Agent の作成

`hello_agent.py` という名前のファイルを作成して、以下のコードを記述します。

```python
import asyncio
import os

from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential
from dotenv import load_dotenv

load_dotenv()


async def main() -> None:
    client = FoundryChatClient(
        project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
        model=os.environ.get("FOUNDRY_MODEL", "gpt-4.1"),
        credential=AzureCliCredential(),
    )

    agent = Agent(
        client=client,
        name="HelloAgent",
        instructions="あなたは親切な AI アシスタントです。日本語で簡潔に回答してください。",
    )

    # 通常応答
    result = await agent.run("Microsoft Foundry とは何ですか？ひとことで教えてください。")
    print(f"Agent: {result}")

    # ストリーミング応答
    print("Agent (streaming): ", end="", flush=True)
    async for chunk in agent.run(
        "AI エージェントの活用例を 1 つだけ教えてください。",
        stream=True,
    ):
        if chunk.text:
            print(chunk.text, end="", flush=True)
    print()


if __name__ == "__main__":
    asyncio.run(main())
```

### 2-3. スクリプトの実行

以下のコマンドでスクリプトを実行します。

```bash
python hello_agent.py
```

正常に実行されると、まず通常応答が表示され、その後ストリーミングで回答が順次表示されます。

![](../images/3-2-02.png)

## 3. ツールを使ったエージェントの作成

### 3-1. 関数ツールの追加

最新の Microsoft Agent Framework SDK では、`@tool` デコレーターを使って Python 関数をツールとしてエージェントに渡せます。

`weather_agent.py` という名前のファイルを作成して、以下のコードを記述します。

```python
import asyncio
import os
from typing import Annotated

from agent_framework import Agent, tool
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential
from dotenv import load_dotenv
from pydantic import Field

load_dotenv()


@tool(approval_mode="never_require")
def get_weather(
    location: Annotated[str, Field(description="天気を知りたい場所")],
) -> str:
    """指定された場所の天気を返すサンプルツール"""
    sample = {
        "Tokyo": "晴れ、最高気温 24°C",
        "Osaka": "雨、最高気温 22°C",
        "Sapporo": "くもり、最高気温 18°C",
    }
    return f"{location} の天気は {sample.get(location, '晴れ、最高気温 25°C')} です。"


async def main() -> None:
    client = FoundryChatClient(
        project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
        model=os.environ.get("FOUNDRY_MODEL", "gpt-4.1"),
        credential=AzureCliCredential(),
    )

    agent = Agent(
        client=client,
        name="WeatherAgent",
        instructions="あなたは天気案内エージェントです。質問に答えるときは get_weather ツールを使ってください。",
        tools=[get_weather],
    )

    result = await agent.run("東京の天気を教えてください。")
    print(f"Agent: {result}")


if __name__ == "__main__":
    asyncio.run(main())
```

```bash
python weather_agent.py
```

> サンプルでは `approval_mode="never_require"` を使っていますが、本番運用では承認フローの追加を検討してください。

## 4. 複数ターンの会話への対応

Microsoft Agent Framework SDK では、同じセッションを使い回すことで会話の文脈を維持できます。

`multi_turn_agent.py` という名前のファイルを作成して、以下のコードを記述します。

```python
import asyncio
import os

from agent_framework import Agent
from agent_framework.foundry import FoundryChatClient
from azure.identity import AzureCliCredential
from dotenv import load_dotenv

load_dotenv()


async def main() -> None:
    client = FoundryChatClient(
        project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
        model=os.environ.get("FOUNDRY_MODEL", "gpt-4.1"),
        credential=AzureCliCredential(),
    )

    agent = Agent(
        client=client,
        name="ConversationAgent",
        instructions="あなたは会話の文脈を理解する AI アシスタントです。日本語で簡潔に回答してください。",
    )

    session = agent.create_session()

    result = await agent.run("私の名前は Annie で、趣味はランニングです。", session=session)
    print(f"Agent: {result}\n")

    result = await agent.run("私について覚えていることを教えてください。", session=session)
    print(f"Agent: {result}")


if __name__ == "__main__":
    asyncio.run(main())
```

```bash
python multi_turn_agent.py
```

## 5. マルチエージェントワークフローの作成

複数のエージェントを順番に連携させるワークフローも、最新の SDK では簡潔に記述できます。ここでは、下書きを作るエージェントとレビューするエージェントを順番につなぎます。

- **writer**: たたき台の文章を作成する
- **reviewer**: writer の出力を見て改善する

### 5-1. ワークフローの実装

`multi_agent_workflow.py` という名前のファイルを作成して、以下のコードを記述します。

```python
import asyncio
import os
from typing import cast

from agent_framework import Agent, Message
from agent_framework.foundry import FoundryChatClient
from agent_framework.orchestrations import SequentialBuilder
from azure.identity import AzureCliCredential
from dotenv import load_dotenv

load_dotenv()


async def main() -> None:
    client = FoundryChatClient(
        project_endpoint=os.environ["FOUNDRY_PROJECT_ENDPOINT"],
        model=os.environ.get("FOUNDRY_MODEL", "gpt-4.1"),
        credential=AzureCliCredential(),
    )

    writer = Agent(
        client=client,
        name="writer",
        instructions="ユーザーの依頼に対して、簡潔な説明文を日本語で作成してください。",
    )

    reviewer = Agent(
        client=client,
        name="reviewer",
        instructions="直前の回答をレビューし、より分かりやすい改善案を日本語で返してください。",
    )

    workflow = SequentialBuilder(participants=[writer, reviewer]).build()

    outputs: list[list[Message]] = []
    async for event in workflow.run(
        "Microsoft Foundry の特徴を 3 つ挙げてください。",
        stream=True,
    ):
        if event.type == "output":
            outputs.append(cast(list[Message], event.data))

    if outputs:
        print("===== Final Conversation =====")
        for msg in outputs[-1]:
            speaker = msg.author_name or msg.role
            if msg.text:
                print(f"[{speaker}] {msg.text}")


if __name__ == "__main__":
    asyncio.run(main())
```

### 5-2. ワークフローの実行

```bash
python multi_agent_workflow.py
```

ワークフローが順に実行され、最終的に reviewer が整えた回答が表示されます。

![](../images/3-4-01.png)

> **動作の流れ**
> 1. ユーザーの入力を writer が受け取ります。
> 2. writer の出力を reviewer が引き継いで確認します。
> 3. reviewer が改善済みの最終回答を返します。

## まとめ

本ハンズオンでは、Microsoft Agent Framework SDK を使って以下を実装しました。

| 内容 | 概要 |
|---|---|
| シンプルなエージェントの作成 | `Agent` と `FoundryChatClient` を使った基本的な実装方法 |
